The first public release of Spacetile.

Spacetile is a window manager that works with your Mac. It tiles windows on the native Spaces you create in Mission Control, and keeps the drag and resize gestures you already know.

## New

- Signed and notarized by Kodehort Ltd, so it opens without Gatekeeper warnings.
- Updates itself. Spacetile checks once a day and shows the release notes before installing. Check now with Check for Updates… in the menu bar panel or Settings → General.
- Pick a Channel in Settings → General: Stable, Beta for pre-releases, or Nightly for the latest build each day it changes.

Read the docs at [spacetile.app](https://spacetile.app/docs/).
