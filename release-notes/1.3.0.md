## New

- Each display can have its own Desktop labels. In Settings → Spaces, pick a display under **Labels for** and label its Desktops; one left empty shows the label set for all displays. Identical monitors are told apart by their order in the arrangement, so swapping them swaps their labels.

## Changed

- Focus follows mouse and Mouse follows focus are off on a new install. Turn them on in Settings → General. Settings you've already chosen stay as they are; Restore Defaults turns them off.

## Fixed

- A profile captured with two monitors of the same model now keeps each monitor's Desktops apart. Monitors that report the same serial number were recorded as one display, so loading the profile put both monitors' windows on one of them. Capture the profile again to pick up the fix.
- Waking the Mac no longer leaves a display's windows gathered on one Desktop. macOS sometimes moves them there several seconds after waking, and Spacetile took that as you moving them; now, for a minute after the Mac wakes or displays change, it puts such windows back on their own Desktops.
- Applying a profile, by hand or after the Mac wakes, no longer swaps an app's windows between displays. An app with several windows, like Chrome, could have its windows traded when it had reopened them in another order since the profile was captured. A window already on a Desktop the profile gives its app now stays there.
