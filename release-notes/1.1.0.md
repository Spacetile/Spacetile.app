## New

- Point releases are free. A Licence that covers a version (X.Y.0) also covers every point release of it (X.Y.1, X.Y.2 and so on), which hold fixes only.
- Security fixes install and run for every Licence, whatever its update window.
- The Welcome guide asks you to agree to the End User Licence Agreement, and tiling starts once you do. It shows again whenever the agreement changes. Until then the menu bar shows "Spacetile needs you to agree to its EULA", with Show Welcome Guide….
- Settings → General has an Acknowledgements… button that lists the licences of the open-source code Spacetile includes.

## Improved

- When an update needs a Renewal, the updater and the Licence pane say which update window it needs.
- The Licence pane says prices include VAT, and that a Licence covers every fix to the versions it includes.
